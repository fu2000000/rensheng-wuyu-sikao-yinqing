# 人生五域思考引擎

> 一套帮助你选择正确思考方式的 AI Skill：先问清问题，再学明白、找方案、做决策，并逐步认识自己。

`人生五域思考引擎`（Rensheng Wuyu Thinking Engine）将复杂的思考任务分为 **5 个场景、12 种方法**。当你不知道该如何向 AI 提问，或者面对一个问题不知道应该先澄清、学习、分析还是决策时，它会帮助你选择合适的方法，并按照对应的思考流程展开对话。

## 它解决什么问题

很多时候，问题并不是“AI 不会回答”，而是：

- 自己还没有想清楚真正想问什么；
- 只听懂了概念的比喻，却没有理解底层机制；
- 看到了优秀案例，却不知道哪些经验可以迁移；
- 把事实、推断、观点和价值判断混在了一起；
- 旧方案不断打补丁，却没有回到问题本质；
- 多个选项都有道理，不知道应该如何选择；
- 一直停留在想象中，没有通过现实行动验证；
- 不清楚自己的优势、能量来源和未来方向。

这个 Skill 的核心原则是：

> **先定位问题阶段，再选择思考方法；先澄清事实和目标，再分析方案；先识别关键假设，再设计行动。**

## 五大场景与 12 种方法

### 一、问清问题

#### 1. 苏格拉底式提问

当你感到困惑，却说不清真正的问题时使用。它通过逐轮追问，区分事实、解释、价值判断和目标，最后把模糊困惑整理成一个准确、可以行动的新问题。

**适合的问题：**

> “我是不是不适合现在的工作？”

AI 不会马上告诉你该不该辞职，而是先追问“不适合”具体指什么：能力不足、价值观不合、工作内容不喜欢，还是环境让你持续消耗。

### 二、学习

#### 2. 双层解释法

当你想学习一个陌生概念，又不想只停留在“好像听懂了”的阶段时使用。它先用小白语言建立直觉，再用专业术语解释机制、边界和常见误解，最后用问题检查是否真正理解。

**适合的问题：**

> “请用双层解释法讲讲什么是向量数据库。”

#### 3. 反向拆解

当你面对一个优秀的网站、产品、方案、文章或流程，想知道它为什么有效、哪些规律可以复用时使用。它会从目标、用户、结构、关键选择和完成标准反推作品的有效性。

**适合的问题：**

> “这个落地页为什么转化效果好？请拆解它的结构，并给我一份可以照着执行的制作清单。”

#### 4. 横纵分析法

当你想系统研究一个产品、公司、人物、技术、行业或事件时使用。纵向分析它如何发展到今天，横向比较它与其他对象的差异，再结合历史路径依赖推演未来可能出现的方向。

**适合的问题：**

> “请用横纵分析法研究新能源汽车行业的发展历史、主要竞争者和未来可能的三条路径。”

#### 5. 事实核查

当你想判断一条观点、数据、新闻、研究结论或方案是否可信时使用。它不只核查事实真假，还会检查这些事实能否推出原来的结论，以及其中是否混淆了相关性与因果关系。

**适合的问题：**

> “有人说远程办公一定会降低效率，请帮我做事实核查。”

### 三、解决问题

#### 6. 专家会诊

当一个问题同时涉及多个专业领域，单一视角容易遗漏风险时使用。Skill 会选择三个真正互补的视角，让它们分别提出方案、指出风险并相互质疑，最后形成综合方案。

**适合的问题：**

> “请从用户体验、技术架构和合规风险三个视角，评估是否应该上线 AI 客服。”

#### 7. 第一性原理

当现有方案越来越复杂、不断打补丁，或者被“行业惯例”和“以前一直这么做”束缚时使用。它会把问题拆回基本事实、未经验证的假设、真实目标和现实约束，再重新推导解决路径。

**适合的问题：**

> “我们通过增加会议解决沟通问题，但会议越来越多。请用第一性原理重新分析。”

#### 8. 跨领域借解

当本行业的常规方法解决不了问题，想从其他领域获得启发时使用。它会先抽象问题的底层结构，再从历史案例和至少三个距离较远的领域中寻找可迁移的解决机制，并设计一个小型实验。

**适合的问题：**

> “我们的内容选题越来越同质化，请从生物学、金融和城市交通中寻找可以借鉴的机制。”

### 四、决策

#### 9. 双向钢人论证

当两个或多个选项都有充分理由，不希望 AI 只替你支持某一方时使用。它会分别构建每个选项最强的支持理由、最大收益、主要风险和最难回答的反对意见，再找出最可能改变结论的关键变量。

**适合的问题：**

> “我在留在大公司和加入创业公司之间犹豫，请做双向钢人论证，不要先替我做决定。”

#### 10. 用最小实验替代空想

当继续讨论无法获得更多信息，而现实反馈可以帮助判断时使用。它会围绕最关键的假设，设计一个低成本、可逆、有明确指标和停止条件的短期实验。

**适合的问题：**

> “我想转行做自由职业，但不确定有没有客户，请帮我设计一个 14 天内可以完成的最小实验。”

### 五、认识自己

#### 11. 挖掘隐藏天赋

当你想知道自己真正擅长什么、什么事情会让自己恢复能量，以及哪些能力可能被误解成缺点时使用。它会从童年经历、无意识胜任区、反复被批评的特点、嫉妒对象和能量模式中寻找可迁移的底层能力。

这不是职业测评，也不是心理诊断，而是基于具体经历提出可验证的能力假设。

**适合的问题：**

> “我总觉得自己没有特别擅长的东西，请通过多轮提问帮我挖掘隐藏天赋，每次只问一个问题。”

#### 12. 人生设计术

当你想探索未来方向、重新定义当前困境，并设计几种值得尝试的人生可能性时使用。它会区分无法改变的“重力问题”和可以设计的“真问题”，再结合工作观、人生观、心流和能量模式，生成三个不同的五年人生版本。

**适合的问题：**

> “我不知道应该继续晋升、转行还是做自己的项目，请陪我设计三个不同的五年人生版本。”

## 如何安装

### 方式一：通过 God Agent 从 GitHub 安装

将本项目发布到 GitHub 后，在 God Agent 中使用 Skill 导入功能：

1. 打开 Skill 管理或导入入口；
2. 选择从 GitHub 导入；
3. 输入本仓库地址，例如：

   ```text
   https://github.com/<你的用户名>/<你的仓库名>
   ```

4. 在扫描结果中选择 `rensheng-wuyu-sikao-yinqing`；
5. 确认安装；
6. 安装完成后，重新开始一个对话，或在当前对话中重新加载可用 Skill。

如果一个仓库包含多个 Skill，请在扫描结果中选择名称为 `rensheng-wuyu-sikao-yinqing` 的 Skill，而不是直接安装整个仓库。

### 方式二：使用 Skill 管理功能导入

如果你使用的是支持 Skill 管理的 God Agent 客户端，可以通过 Skill 导入功能指定 GitHub 仓库：

```text
导入 Skill：<你的 GitHub 仓库地址>
```

客户端会扫描仓库中的 Skill，并要求你选择和确认要安装的 Skill。请在确认前检查 `SKILL.md` 的内容、来源说明和权限范围。

### 方式三：手动安装

如果你的客户端支持手动管理 Skill，可以将本项目中的 Skill 目录复制到用户级 Skill 目录：

```text
~/.god-agent/skills/rensheng-wuyu-sikao-yinqing/
```

目录至少应包含：

```text
rensheng-wuyu-sikao-yinqing/
└── SKILL.md
```

Windows 用户通常可以在以下位置找到对应目录：

```text
C:\Users\<你的用户名>\.god-agent\skills\rensheng-wuyu-sikao-yinqing\
```

复制完成后，重新启动客户端或重新加载 Skill 列表。

> 不同客户端版本的 Skill 目录和导入入口可能略有不同。优先使用客户端提供的 GitHub 导入功能。

## 如何使用

安装后，你不需要记住 12 个 Prompt，也不需要每次手动复制完整模板。直接用自然语言描述问题即可，Skill 会根据你的目标和卡点选择合适的方法。

### 让 Skill 自动选择方法

```text
我不知道这个问题应该用哪种思考方法。
我最近想从产品经理转行做独立开发，但不知道自己是真的想做，还是只是羡慕别人的结果。请先帮我判断应该使用哪个 Prompt，再开始。
```

Skill 会先判断你处于哪个阶段，并说明推荐的方法和原因。

### 直接指定方法

你也可以直接指定想使用的方法：

```text
请用双层解释法讲讲什么是大语言模型。
```

```text
请用第一性原理分析一下，为什么我们的会议越来越多。
```

```text
请用双向钢人论证，帮我比较留在大公司和加入创业公司。
```

```text
请用最小实验的方法，帮我验证自由职业是否适合我。
```

### 在对话中提供材料

根据任务类型，尽量提供相关材料：

- 学习概念：提供术语、背景和自己的基础；
- 反向拆解：提供网页、产品、文章、方案或截图；
- 横纵分析：提供研究对象、时间范围和重点问题；
- 事实核查：提供原始说法、数据、链接和上下文；
- 专家会诊：提供目标、已知事实、资源和现实约束；
- 决策分析：提供选项、目标、底线和可接受的代价；
- 自我探索：尽量提供具体事件、年龄、行动、感受和结果，不要只给抽象评价。

### 互动型方法需要逐轮回答

以下方法不是一次性报告，而是对话流程：

- 苏格拉底式提问；
- 挖掘隐藏天赋；
- 人生设计术；
- 双向钢人论证的第一阶段。

使用时，AI 会一次问一个问题。尽量回答具体经历，而不是只回答“还好”“不知道”或“我比较喜欢挑战”。例如：

```text
我在大学时主动帮社团重新设计活动流程。没人要求我这么做，但我连续几个晚上研究报名数据和参与者反馈，最后把报名率提高了。
```

具体信息越多，后续判断越有价值。

## 推荐的组合用法

复杂问题通常不只适合一个方法，可以按下面的顺序组合：

### 从模糊困惑到行动

```text
苏格拉底式提问
→ 事实核查
→ 第一性原理或专家会诊
→ 最小实验
```

### 学习一个陌生领域

```text
事实核查
→ 双层解释法
→ 横纵分析法
→ 反向拆解一个优秀案例
```

### 做一个重要选择

```text
苏格拉底式提问
→ 双向钢人论证
→ 最小实验
→ 根据实验结果做决定
```

### 探索职业和人生方向

```text
挖掘隐藏天赋
→ 人生设计术
→ 为不同方向设计原型行动
```

## 使用注意事项

### 它不是万能答案生成器

Skill 的目标是改善思考过程，不是保证结论一定正确。对于重大职业、财务、医疗、法律和人生决定，请结合专业人士意见和现实证据。

### 事实核查不等于绝对真相

核查结果取决于资料质量、时间范围、样本和来源。对于证据不足或存在争议的内容，Skill 会明确标注不确定性，不应把“暂未核实”当成“已经证伪”。

### 自我探索结果不是诊断

“挖掘隐藏天赋”和“人生设计术”输出的是基于经历的假设、方向和验证建议，不是心理诊断、人格定论或命运预测。如果你处于明显的心理危机或持续痛苦状态，请寻求合格的心理健康专业人士帮助。

### 重要决定优先做小实验

对于可逆的问题，优先通过低成本实验获得真实反馈，不要仅凭 AI 的分析做不可逆决定。
